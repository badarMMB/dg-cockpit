# Index des Écrans UI Stitch (Executive Admin Cockpit)

Ce dossier `stitch_screens/` contient les maquettes HTML générées par Stitch pour le projet **Executive Admin Cockpit**. Ces écrans sont fournis à titre de référence pour Claude Code afin de faciliter l'intégration et la compréhension du Design System.

## Liste des écrans disponibles (HTML)

1. **Tableau de Bord DG**
   - Fichier : `stitch_screens/tableau_de_bord.html`
   - Description : Interface principale d'accueil du Directeur Général avec les statistiques clés.

2. **Flux des Instructions (Chat-Ops)**
   - Fichier : `stitch_screens/flux_instructions.html`
   - Description : Interface de messagerie et de suivi des dossiers.

3. **Courrier Arrivé**
   - Fichier : `stitch_screens/courrier_arrive.html`
   - Description : Tableau de bord de suivi des courriers entrants.

4. **Courrier Départ**
   - Fichier : `stitch_screens/courrier_depart.html`
   - Description : Tableau de bord de suivi des courriers sortants.

5. **Notes de Service**
   - Fichier : `stitch_screens/notes_service.html`
   - Description : Interface de rédaction et publication des notes de service.

6. **Gestion des Rendez-vous**
   - Fichier : `stitch_screens/gestion_rdv.html`
   - Description : Module d'agenda et gestion des visiteurs (avec intégration de QR Code).

7. **Signature Électronique**
   - Fichier : `stitch_screens/signature.html`
   - Description : Interface de validation et de signature des documents.

## Notes pour Claude Code
- Ces fichiers contiennent le HTML brut généré par Stitch, incluant les classes utilitaires Tailwind CSS et la structure DOM.
- Utilisez-les comme source d'inspiration pour le `Design System` et les `Tokens` (Couleurs : *Navy Blue*, typographie : *Inter*).
- Vous pouvez lire le contenu de ces fichiers pour extraire des composants spécifiques (Sidebar, Header, Cards, Modals).
